# AppLanches 📱🛒

## About the Project
**AppLanches** is a cross-platform mobile application built with **.NET MAUI** that connects to the **ECommerceSnacks API**. The app delivers a seamless shopping experience, allowing users to browse products, manage their cart, and complete orders through an intuitive and responsive interface.

## Features 🚀
- 🔐 **User Authentication:** Secure user registration and login with JWT authentication.  
- 🛍️ **Product Catalog:** Browse snack products organized by categories.  
- 🔎 **Product Search and Filtering:** Search and filter products by name, category, or price.  
- 📦 **Product Details:** View detailed product information with images and descriptions.  
- ➕ **Add to Cart:** Add products to the cart with quantity management.  
- 🛒 **Cart Management:** Update quantities, remove items, and view cart summary.  
- 💳 **Checkout Process:** Complete orders with a simple and intuitive checkout flow.  
- ❤️ **Favorites:** Mark and unmark products as favorites for quick access.  
- 👤 **User Profile:** Manage user information and view order history.  
- 📄 **Order Details:** View detailed information about completed orders.  
- ❓ **FAQ Page:** Access frequently asked questions for user support.  
- 🎨 **Modern and Responsive UI:** Clean design optimized for mobile devices.

## Technologies Used 🛠️
- **Framework:** .NET MAUI  
- **Language:** C# 🟦  
- **UI Design:** XAML  
- **Architecture:** MVVM (Model-View-ViewModel)  
- **Backend Integration:** REST API (ECommerceSnacks API)  
- **Authentication:** JWT (JSON Web Tokens)  
- **Platform:** Android, iOS
